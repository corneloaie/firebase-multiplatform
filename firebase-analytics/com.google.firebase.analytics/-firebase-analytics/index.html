FirebaseAnalytics

class FirebaseAnalytics(source)

The entry point of Firebase Analytics, mirroring com.google.firebase.analytics.FirebaseAnalytics; obtained with com.google.firebase.Firebase.analytics.

On Android this class is a header stub for the real one (its bytecode is deleted after compilation); on the other platforms it is real code over the platform SDK. On the JVM it is a no-op, as firebase-java-sdk has no analytics. Constants and enums are shared. The JS SDK has no session timeout, session ID or analytics data reset: those calls do nothing and getSessionId completes with null there.
