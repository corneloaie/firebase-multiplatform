# Module firebase-dataconnect
This module provides the Firebase Data Connect API, `com.google.firebase.dataconnect`, on Android, iOS, tvOS, JS and Wasm:
the Android SDK on Android, the Firebase JS SDK on JS and Wasm (wasmJs) and the Firebase iOS Data Connect SDK (through an
Objective-C wrapper) on Apple. Operations take their variables and the kotlinx.serialization strategies that encode them
and decode their data.
