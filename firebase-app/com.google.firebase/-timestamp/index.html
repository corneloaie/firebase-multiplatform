Timestamp

actual class Timestamp(seconds: Long, nanoseconds: Int) : Comparable<Timestamp> (source)

A point in time with nanosecond precision, mirroring com.google.firebase.Timestamp from the Firebase Android SDK.

The Date and Instant constructors, toDate and toInstant use JVM-only types and can only be called from Android/JVM code: from common code they fail to compile with a message naming the kotlin.time.Instant counterparts, the top-level Timestamp(Instant) function and toKotlinInstant. The Parcelable members are not mirrored.

Parameters

seconds

seconds since the Unix epoch, between -62135596800 and 253402300799 inclusive

nanoseconds

fraction of a second in nanoseconds, between 0 and 999999999 inclusive
