FirebaseInAppMessaging

class FirebaseInAppMessaging(source)

Firebase In-App Messaging: displays the messages of the campaigns created in the Firebase console, with the SDK's default UI or a component set with setMessageDisplayComponent, and reports what the user does with them as flows.

The messages, their actions and the display callbacks are the types of the com.google.firebase.inappmessaging layer, such as InAppMessage and Action. See CompatFirebaseInAppMessaging for the platform differences: on the JVM no message is ever displayed.
