actual class FirebaseInAppMessaging

Firebase In-App Messaging, as the Android SDK's com.google.firebase.inappmessaging.FirebaseInAppMessaging: the headless SDK that fetches the campaigns, decides when a message is due and records its impressions and clicks. A message is rendered by the display component, which is the SDK's default UI unless setMessageDisplayComponent replaces it.

actual class FirebaseInAppMessaging

The iOS SDK's FIRInAppMessaging. There is one instance per FIRInAppMessaging, as the listeners live here: they are fed from its delegate, which this instance sets (and keeps alive, the property being weak) when a listener is added, replacing a delegate set on ios directly.

FirebaseInAppMessagingDisplayCallbacks
Link copied to clipboard
interface FirebaseInAppMessagingDisplayCallbacks

Reports what happens to a message to the SDK, mirroring FirebaseInAppMessagingDisplayCallbacks: a display component receives one with each message. Each call records the event and notifies the matching listeners of FirebaseInAppMessaging; the task completes once it is recorded. On Apple platforms each call is passed to the iOS SDK's display delegate on the main thread, where the iOS SDK expects it, and the task completes after that.
