val InAppMessage.ios: FIRInAppMessagingDisplayMessage?

The iOS SDK's message this one was built from, a FIRInAppMessagingCardDisplay, FIRInAppMessagingModalDisplay, FIRInAppMessagingBannerDisplay or FIRInAppMessagingImageOnlyDisplay. It has what the Android model lacks, such as the trigger type and the downloaded image data (imageRawData).
