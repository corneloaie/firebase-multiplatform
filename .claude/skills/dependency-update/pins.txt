# What the weekly dependency routine must not bump, and why. check_updates.py reads this file; the routine follows it.
#
# One rule per line: <key> <rule> <why>
#   key   a [versions] ref of gradle/libs.versions.toml, a group:artifact hard-coded in a build script, or an action
#         (owner/repo)
#   rule  <X.Y    stay below the X.Y line: newer versions below it are still taken
#         hold    never bump: report what is available, for a person to bump by hand
#         weekly  the weekly workflow (.github/workflows/weekly.yml) moves it: never touch, don't report
# A key may have several lines. Remove a line once its reason is gone, in the same pull request as the bump.

# kotlinx-coroutines 1.11.0 regressed Promise rejection handling on Wasm/JS: a rejected Promise no longer surfaces as
# JsException, so the raw JS error object (and its structured `details`) is unrecoverable through public API.
# GitLive's #855 introduced and then reverted the bump.
kotlinx-coroutines  <1.11   Wasm/JS Promise rejection regression (Kotlin/kotlinx.coroutines#4678)

# dokka 2.2.0 rejects two source sets sharing a source root, and the modules whose jvmMain adds
# kotlin.srcDir("src/androidMain/kotlin") do exactly that, so dokkaGeneratePublicationHtml fails during publishing.
dokka               <2.2    rejects the android/jvm shared source roots (Kotlin/dokka#3701)

# Publishing tooling: pull request CI never runs it (dokka 2.2 passed every check and broke the release), so a bump
# needs a Publish dry run on its branch (gh workflow run publish.yml --ref <branch>) before it merges.
dokka               hold    publishing only: needs a Publish dry run, which the routine never starts
publish             hold    publishing only: needs a Publish dry run, which the routine never starts

# The weekly workflow moves the Firebase SDKs together and regenerates the API coverage reports.
firebase-bom        weekly  Firebase Android BoM
firebase-appdistribution  weekly  App Distribution, not in the BoM, moves to the release its api.txt describes
firebase-ios-sdk    weekly  Firebase iOS SDK (SwiftPM)
