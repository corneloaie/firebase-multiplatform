FirebaseAppDistributionException

open class FirebaseAppDistributionException(source)

The exception that a failed FirebaseAppDistribution task fails with; the Android SDK's FirebaseAppDistributionException. errorCode says why. The iOS SDK's errors map onto Status.UNKNOWN, Status.AUTHENTICATION_FAILURE, Status.AUTHENTICATION_CANCELED and Status.NETWORK_FAILURE.

Plain common code: on Android and the JVM it has the SDK class's constructors, which the SDK hides from its reference documentation.
