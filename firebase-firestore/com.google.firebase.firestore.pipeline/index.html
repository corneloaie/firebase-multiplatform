Expression
Link copied to clipboard
abstract class Expression

An expression of the pipeline API, mirroring com.google.firebase.firestore.pipeline.Expression from the Firebase Android SDK: a field reference, a constant, or a function of the pipeline backend over other expressions. The functions of the companion object create them; the member functions apply the companion function of the same name to this expression, as its first argument. A function taking a field name instead of an expression applies to that field; a value of type Any becomes a constant (see constant).
