Pipeline

class Pipeline(source)

A pipeline: a source (from FirebaseFirestore.pipeline) followed by stages that filter, transform and aggregate the documents, run by execute. Immutable: each stage method returns a new pipeline with the stage appended.

On Apple platforms, execute with ExecuteOptions that set options other than ExecuteOptions.withAtomic, and source stages with options other than the forced index (CollectionHints.withForceIndex), fail: the iOS SDK's pipeline bridge has no way to pass them.
