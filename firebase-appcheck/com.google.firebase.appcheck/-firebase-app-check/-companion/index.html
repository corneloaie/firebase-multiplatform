fun setAppCheckProviderFactory(factory: AppCheckProviderFactory?)

Apple only: sets the provider factory of the apps configured from now on, the iOS SDK's AppCheck.setAppCheckProviderFactory. The iOS SDK reads it when an app is configured, so call this before Firebase.initialize to choose the provider of the default app. null leaves apps configured afterwards without App Check.
