FirebaseAppCheck

actual abstract class FirebaseAppCheck(source)

Firebase App Check, mirroring com.google.firebase.appcheck.FirebaseAppCheck from the Firebase Android SDK. It attests that requests to Firebase backends come from your app, and gives you tokens for your own backend.

Tokens come from the AppCheckProvider of the installed AppCheckProviderFactory. That factory can be com.google.firebase.appcheck.debug.DebugAppCheckProviderFactory, com.google.firebase.appcheck.playintegrity.PlayIntegrityAppCheckProviderFactory (Android only), com.google.firebase.appcheck.recaptcha.RecaptchaAppCheckProviderFactory, or a factory of your own.

The platform SDKs install a factory differently:

  • Android: installAppCheckProviderFactory replaces the provider of this app at any time.

  • Apple: the iOS SDK keeps one factory for the whole process. It reads that factory when an app is configured, and creates the app's App Check then. installAppCheckProviderFactory sets the factory, so it only applies to apps configured afterwards. For the default app, set it before Firebase.initialize from Apple code with FirebaseAppCheck.setAppCheckProviderFactory. Until then the iOS SDK's default applies: the debug provider on a simulator, DeviceCheck on a device.

  • JS: the JS SDK starts App Check for an app once, with its provider (initializeAppCheck). The first installAppCheckProviderFactory does that, and the instance has no token before. Afterwards a factory of your own can still replace another one of your own. The JS SDK's own providers (the debug provider and reCAPTCHA) can neither replace a provider nor be replaced: installAppCheckProviderFactory throws then.
