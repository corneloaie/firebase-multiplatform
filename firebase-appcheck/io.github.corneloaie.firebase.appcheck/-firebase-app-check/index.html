FirebaseAppCheck

class FirebaseAppCheck(source)

Firebase App Check: attests that requests to Firebase backends come from your app, and gives you tokens for your own backend.

Install a provider factory first: one of the factories of the com.google.firebase.appcheck packages (com.google.firebase.appcheck.debug.DebugAppCheckProviderFactory, com.google.firebase.appcheck.playintegrity.PlayIntegrityAppCheckProviderFactory, com.google.firebase.appcheck.recaptcha.RecaptchaAppCheckProviderFactory), a platform-specific one of this package, or your own com.google.firebase.appcheck.AppCheckProviderFactory. When a factory takes effect differs between platforms; see com.google.firebase.appcheck.FirebaseAppCheck.
