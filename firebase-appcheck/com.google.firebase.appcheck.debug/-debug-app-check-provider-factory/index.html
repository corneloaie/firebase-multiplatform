DebugAppCheckProviderFactory

actual class DebugAppCheckProviderFactory : AppCheckProviderFactory(source)

The factory of the debug provider, mirroring com.google.firebase.appcheck.debug.DebugAppCheckProviderFactory (firebase-appcheck-debug). For emulators, simulators and CI: the provider exchanges a debug token for App Check tokens, once you have added that debug token in the Firebase console. Do not use it in builds for real users.

The debug token comes from the platform SDK:

  • Android generates one, keeps it and logs it.

  • Apple reads the AppCheckDebugToken environment variable, or generates one, keeps it and logs it.

  • JS switches the JS SDK to its debug mode (self.FIREBASE_APPCHECK_DEBUG_TOKEN = true, unless the page set a token there itself), which logs a generated token to the console. The JS SDK reads that setting the first time App Check starts in the page, so install this factory before any other.
