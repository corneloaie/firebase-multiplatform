FirebaseMessaging

actual class FirebaseMessaging(source)

Firebase Cloud Messaging, as the Android SDK's com.google.firebase.messaging.FirebaseMessaging. Receiving messages is platform code on every platform (FirebaseMessagingService on Android).

The JS SDK has no topic subscription (a web client's token is subscribed from a server with the Admin SDK) and no auto-init (a token is only ever generated by getToken): those members do nothing on JS and carry @UnsupportedOnJs, so code compiled for JS gets a warning until it opts in.
