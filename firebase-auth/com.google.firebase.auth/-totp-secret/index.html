expect interface TotpSecret(source)

A TOTP secret to enroll an authenticator app with, mirroring com.google.firebase.auth.TotpSecret.

The iOS SDK exposes only the shared secret, the QR code URL and the OTP app hand-off: on Apple platforms the hash algorithm and the code length are read from the QR code URL, and codeIntervalSeconds, enrollmentCompletionDeadline and sessionInfo throw UnsupportedOperationException. The JS SDK keeps the session private, so sessionInfo throws there too.
