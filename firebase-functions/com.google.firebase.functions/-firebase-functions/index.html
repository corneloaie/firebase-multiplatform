The entry point for Cloud Functions for Firebase, mirroring com.google.firebase.functions.FirebaseFunctions from the Firebase Android SDK: creates references to callable HTTPS functions.

Not mirrored: useFunctionsEmulator (deprecated in the Android SDK, use useEmulator).
