URL

class URL(source)

Deprecated (with error)

java.net.URL is a JVM-only type with no multiplatform counterpart: pass the URL as a String (getHttpsCallableFromUrl(url) takes one)

Stands in for java.net.URL so that the Firebase Android SDK members taking one can be declared in common code and deprecated with an error naming their String counterparts. java.net.URL is JVM-only: a value of this type cannot exist in common code, so the class has no members and cannot be constructed. On Android and the JVM the class is a header stub that is stripped from the output (see buildSrc utils/HeaderStubs.kt), so code there uses the JDK's.
