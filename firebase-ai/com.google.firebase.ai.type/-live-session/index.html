Represents a live WebSocket session capable of streaming content to and from the server.

actual class LiveSession(source)

A Live API session of the platform SDK. The messages of the server are buffered from the moment the session opens until they are received. resumeSession opens a new session of the platform SDK and closes the current one, as the Android SDK does.

The platforms other than Android have no audio conversation of the SDK's own (the Android SDK records and plays the audio itself): startAudioConversation does nothing there, so stream audio with sendAudioRealtime and play the audio parts the server sends.
