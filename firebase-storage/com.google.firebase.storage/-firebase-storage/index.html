Cloud Storage for Firebase, as the Android SDK's com.google.firebase.storage.FirebaseStorage. The download retry time, file downloads and FileDownloadTask exist on Android, the JVM and Apple platforms (nonJsMain); the JS SDK downloads through URLs only.
