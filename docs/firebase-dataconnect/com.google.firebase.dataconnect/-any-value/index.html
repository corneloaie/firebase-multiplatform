class AnyValue(source)

The value of a Data Connect Any scalar: a String, a Boolean, a Double, a List of such values (or null) or a Map from String to such values (or null). A null scalar is represented by null rather than by an AnyValue.

The Android SDK keeps the value as a protobuf Value; this class keeps the plain Kotlin value, which is what value returns on both. Numbers other than Double given to fromAny are converted to Double, as the wire format has only that number type.
