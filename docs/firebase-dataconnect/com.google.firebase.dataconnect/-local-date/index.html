LocalDate

class LocalDate(val year: Int, val month: Int, val day: Int)(source)

A calendar date without a time zone, the Kotlin form of the Data Connect Date scalar. month and day are 1-based; the values are not validated, so that dates from a server can be represented as sent.

Plain common code shared by every platform (the Android SDK's class has the same members); the conversions to and from java.time.LocalDate exist on the Android SDK only, use toKotlinxLocalDate and toDataConnectLocalDate from common code.
