FirebaseAppDistribution

class FirebaseAppDistribution(source)

Firebase App Distribution's in-app tester API: signs the tester in, checks for new pre-release builds, updates the app to them and collects the tester's feedback.

On Android it does nothing (and fails with AppDistributionExceptionStatus.NOT_IMPLEMENTED) unless the app's pre-release builds add the full com.google.firebase:firebase-appdistribution SDK. On iOS an update opens the new release's download link, and there is no in-app feedback. The JVM has no App Distribution. See com.google.firebase.appdistribution.FirebaseAppDistribution for each member's behaviour per platform.

updateApp
Link copied to clipboard
fun updateApp(): Flow<UpdateProgress>

Updates the app to the release that the last checkForNewRelease returned. Collecting the flow starts the update; it emits the update's progress, completes when the update has, and throws the FirebaseAppDistributionException the update failed with (AppDistributionExceptionStatus.UPDATE_NOT_AVAILABLE without a new release). Cancelling the collection does not cancel the update. On iOS it emits nothing: the release's download link is opened, and iOS asks the tester to install it.
