The Firebase App Distribution in-app tester API, mirroring com.google.firebase.appdistribution.FirebaseAppDistribution from the Firebase Android SDK's API-only library (firebase-appdistribution-api): signs the tester in, checks for new pre-release builds, updates the app to them and collects the tester's feedback.

  • Android: every call does nothing, and every task fails with FirebaseAppDistributionException.Status.NOT_IMPLEMENTED, unless the app also depends on the full com.google.firebase:firebase-appdistribution SDK. Add it to pre-release build variants only: its self-update code may break Google Play policy.

  • iOS: backed by the iOS SDK (FirebaseAppDistribution-Beta), which provides sign-in and the release check; updateApp and updateIfNewReleaseAvailable open the new release's download link, and iOS then asks the tester to install it. The iOS SDK has no in-app feedback, so the feedback members do nothing there and carry @UnsupportedOnApple. macOS and tvOS have no App Distribution SDK.

  • JVM: behaves as Android does without the full SDK.

Updates the app to the newest release, if one is available. If the tester is not signed in, asks them to sign in first, then checks for a new release; the task succeeds when there is none. Otherwise, after the tester confirms, an APK is downloaded and installed, and an AAB is handed to the Play app.
