GenerativeModel

actual class GenerativeModel(source)
expect class GenerativeModel(source)

Represents a multimodal model (like Gemini), capable of generating content based on various input types.

On Android the model also takes an android.graphics.Bitmap prompt in generateContent, generateContentStream and countTokens; send images as InlineDataParts in common code.

actual class GenerativeModel(source)

A model of the cloud backend, over the platform SDK. The platforms other than Android have no on-device model (as Android without the firebase-ai-ondevice library): OnDeviceConfig modes that prefer one of the two fall back to the cloud, ONLY_ON_DEVICE fails with FirebaseAIOnDeviceNotAvailableException, and onDeviceExtension is null.
