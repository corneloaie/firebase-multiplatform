The exception that Phone Number Verification fails with; the Android SDK's FirebasePhoneNumberVerificationException.

On Android it is the SDK class. It is an expect class rather than plain common code because its cause may be null, which the Android SDK's FirebaseException constructor does not accept from Kotlin.

Parameters

errorCode

why the operation failed, see errorCode.

message

the description of the failure.

cause

the exception that caused the failure. Without one, the exception gets a cause whose message is FirebasePnvStatusCodes.getMessage of errorCode, as the Android SDK gives it.

actual class FirebasePhoneNumberVerificationException(val errorCode: Int, message: String, cause: Throwable?)(source)

The exception that Phone Number Verification fails with. Its message is the one given, as on Android: the JS FirebaseException would append the cause's message to it.
