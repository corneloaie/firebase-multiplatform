Firebase Phone Number Verification, mirroring com.google.firebase.pnv.FirebasePhoneNumberVerification from the Firebase Android SDK (com.google.firebase:firebase-pnv): gets the phone number of a SIM in the device directly from its carrier, with a token signed by Firebase for your backend to verify, instead of sending an SMS code.

Phone Number Verification exists on Android only: Firebase has no iOS, web or Java SDK for it.

  • Android: the SDK itself. getVerifiedPhoneNumber (the extension, for common code, or the SDK's member taking an android.content.Context) needs an Activity.

  • iOS, macOS, tvOS, JS and Wasm: every task fails with UnsupportedOperationException and enableTestSession does nothing. Their members carry @UnsupportedOnApple or @UnsupportedOnJs, which warn where code compiled for those platforms calls them; keep an SMS sign-in (Firebase Authentication's phone sign-in) for them.
