VerifiedPhoneNumberTokenResult

actual class VerifiedPhoneNumberTokenResult(token: String)(source)

A verified phone number with its Firebase PNV token, mirroring com.google.firebase.pnv.VerifiedPhoneNumberTokenResult; from FirebasePhoneNumberVerification.getVerifiedPhoneNumber and FirebasePhoneNumberVerification.exchangeCredentialResponseForPhoneNumber. Send getToken to your backend, which verifies its signature: this class only reads the claims of the token, without verifying it.

Constructing one parses token, a JWT. It throws a FirebasePhoneNumberVerificationException with FirebasePnvStatusCodes.INVALID_DIGITAL_CREDENTIAL_RESPONSE when the token is empty, does not have three parts, or its payload is not a base64url-encoded JSON object. On Android this is the SDK class (also Parcelable); the other platforms parse the token the same way.

actual fun getClaims(): Map<String, Any>

Every claim of the token, sorted by name. A JSON string is a String, true and false are a Boolean, a number is an Int, a Long (when it does not fit in an Int) or a Double (when it has a fraction or an exponent). Nested objects and arrays are org.json.JSONObject and JSONArray on Android, Map and List elsewhere; a claim whose value is null is org.json.JSONObject.NULL on Android and left out elsewhere.
