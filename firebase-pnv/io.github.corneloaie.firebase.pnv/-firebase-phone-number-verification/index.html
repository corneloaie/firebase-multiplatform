FirebasePhoneNumberVerification

class FirebasePhoneNumberVerification(source)

Firebase Phone Number Verification: gets the phone number of a SIM in the device directly from its carrier, with a token signed by Firebase for your backend to verify, instead of sending an SMS code.

It exists on Android only. On iOS, macOS, tvOS, JS and Wasm every operation throws UnsupportedOperationException and enableTestSession does nothing; keep an SMS sign-in for them. See com.google.firebase.pnv.FirebasePhoneNumberVerification for each member's behaviour.

getVerifiedPhoneNumber

suspend fun getVerifiedPhoneNumber(context: Any): VerifiedPhoneNumberTokenResult

Verifies the phone number of a SIM in the device: asks the user for consent through the Android Credential Manager, gets the number from the carrier, and returns it with its Firebase PNV token, which your backend verifies. context is an android.content.Context that is, or wraps, an android.app.Activity. Throws a FirebasePhoneNumberVerificationException if the verification fails.
